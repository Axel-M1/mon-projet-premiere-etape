## MonProjet - Première Étape

Ce dépôt contient une base simple pour démarrer un projet web.

### Structure

- `index.html` : page principale
- `style.css` : styles du site
- `script.js` : interactions simples

### Lancer le projet localement

Ouvrez simplement le fichier `index.html` dans un navigateur ou utilisez un petit serveur local :

```bash
cd premier-etape
python -m http.server 8000
```

Ensuite, ouvrez : http://localhost:8000

### Étapes suivantes

1. Ajouter la vraie logique du projet
2. Créer les composants ou pages
3. Initialiser le dépôt GitHub distant
4. Commencer les tests et la mise à jour continue
